# 中英文多语言支持设计（GUI 范围）

日期：2026-11-26
状态：已确认，待实现

## 目标

设置界面、托盘菜单与 tooltip、daemon 桌面通知支持中英文。新增
`language = "auto" | "zh" | "en"` 配置，默认 `auto` 跟随系统环境。

## 非目标

- CLI 帮助与输出文本、README/文档、悬浮窗显示项 label（属用户配置，不翻译）。
- GTK 设置界面的运行时动态重排（切换语言后重新打开设置界面生效）。
- 除中英文外的其它语言、外部翻译文件（PO/Fluent）。

## 现状

- 托盘：菜单项与 tooltip 英文硬编码（`crates/tray/src/lib.rs`）。
- daemon：告警指标 label、事件消息、通知标题中文硬编码
  （`crates/daemon/src/alerts.rs`，通知经 `org.freedesktop.Notifications`）。
- 设置界面：中文硬编码（`frontends/settings/src/window.rs`）。
- 无任何 i18n 依赖。

## 架构

```
Config.language ─┐
                 ├─> core::i18n::resolve() ─> Language::{Zh,En} ─> tr(key)
LC_ALL / LANG ───┘        ▲                        ▲
                          │                        │
        daemon 告警/通知   托盘菜单(配置变更重建)   设置界面(启动时渲染)
```

翻译实现选 core 内置静态翻译表，不引入第三方 i18n 框架。

## core

`crates/core/src/i18n.rs`：

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Language { Zh, En }

/// 读取 LC_ALL/LANG；`zh` 开头视为中文，其余（含未设置/C）为英文。
pub fn detect() -> Language;

/// 配置为 "zh"/"en" 时直接使用，"auto"（含空串与未知值）回退 detect()。
pub fn resolve(configured: &str) -> Language;

/// 取文案；未知 key 回退英文表，仍无则返回 key 本身，绝不 panic。
pub fn tr(lang: Language, key: &'static str) -> &'static str;
```

文案集中在同文件的 `ZH` / `EN` 两个静态表（`&[(&str, &str)]`），key 按模块命名：
`tray.*`、`notify.*`、`alert.*`、`settings.*`。所有用户可见字符串都必须有 key。

`crates/core/src/config.rs`：`Config` 新增
`#[serde(default = "default_language")] pub language: String`，默认 `"auto"`；
`validate()` 接受 `auto|zh|en`，其它值报错。

## daemon

- `alerts.rs` 的指标 label、`超过阈值`/`已恢复` 等消息、通知标题改为
  `tr(lang, ...)`；`lang` 来自当前配置的 `i18n::resolve`。
- 配置热加载后新告警即按新语言发送；已发出的历史通知不回溯。
- D-Bus `GetConfig` 返回增加 `language s`；`UpdateConfig` 接受 `language`，
  非法值由 `Config::validate` 拒绝。

## 托盘

- 菜单 label 与 tooltip 文案改由 `tr()` 生成。
- 托盘已订阅配置/快照；语言变化时重建 DBusMenu 菜单树，tooltip 同步更新。
- 默认英文系统下托盘保持现有英文文案；中文系统下显示中文。

## 设置界面

- 「通用」页新增语言下拉：`auto`（跟随系统）/ `中文` / `English`，
  保存写入 `language`。
- `frontends/settings` 依赖 `trafficview-core` 的 i18n 模块（路径依赖，
  不引入 GTK 到 core）。
- 全部页面标题、组标题、控件 label/subtitle、按钮、横幅改为 `tr()`。
- 语言切换保存后：托盘立即生效；设置界面顶部 toast 提示
  "重新打开设置界面后生效" / "Reopen settings to apply"。
- 关于页的功能介绍文案随语言切换（GitHub 链接不变）。

## 错误处理

| 场景 | 行为 |
| --- | --- |
| `LANG` 未设置或为 `C`/`POSIX` | 英文 |
| 配置 `language` 为非法值 | `validate()` 报错，拒绝保存 |
| 翻译 key 缺失 | 回退英文；英文也缺失则显示 key，不 panic |
| 旧配置无 `language` 字段 | serde 默认 `auto` |
| 旧 D-Bus 客户端 | 新增 `language s` 键，无影响 |

## 测试

- `core::i18n`：`zh_CN.UTF-8`/`zh_TW`/`en_US`/`C`/未设置的检测；显式覆盖优先于
  环境；未知 key 回退。
- `core::config`：默认 `auto`、非法值校验失败、旧 TOML 兼容。
- `daemon`：告警消息与通知标题随语言切换；D-Bus `language` 读写往返。
- 托盘与设置界面既有测试保持通过；`tr()` 的全 key 在 ZH/EN 表中均存在
  （用一个遍历测试保证两表 key 集合一致）。

## 风险

- 设置界面切换语言需重开窗口，体验折中已确认。
- 文案集中在 core 后，新增界面文本必须同步补两种语言，由"两表 key 一致"
  测试兜底。
