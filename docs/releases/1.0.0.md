# TrafficView 1.0.0 发行说明

发布日期：2026-11-24
发行产物：`trafficview_1.0.0-1_amd64.deb`（6.2 MB）

TrafficView 是一个 Linux 桌面实时流量与系统负载监控工具。核心是一个只读 `/proc`、sysfs
与 netlink 的守护进程，通过 D-Bus 提供数据；悬浮窗、托盘、命令行和设置界面都只订阅
D-Bus，不各自读取系统文件。

## 本版亮点

- **X11 悬浮窗**：上下行速率、CPU、内存等显示项；可拖动、悬停穿透、调透明度、置顶，
  皮肤用 TOML 描述并支持阈值变色，位置与透明度即时持久化。
- **托盘图标**（StatusNotifierItem + DBusMenu）：暂停/恢复、显示/隐藏悬浮窗、切换网卡、
  打开设置界面或配置文件、退出。
- **历史统计**：SQLite 按分钟、日、月聚合，`trafficview history today|month` 查询。
- **告警**：阈值 + 持续时间 + 冷却时间 + 静默时段，触发后发送桌面通知。
- **多前端输出**：`text`、`json`、`waybar`、`polybar`、`tmux`，便于集成到状态栏。
- **设置界面**：独立 GTK4 + libadwaita 程序，覆盖通用、网络、显示、告警、历史、插件
  六个页面；通过 D-Bus 整体提交配置，由守护进程校验并原子保存。
- **采集能力**：netlink `IFLA_STATS64`（网速）、`/proc/stat`（CPU）、`/proc/meminfo`
  （内存）、`/proc/diskstats`、`/proc/mounts`、`/proc/uptime`，以及 sysfs 中的电池、
  温度与 GPU。不可用的采集器不会伪造零值，而是返回 `available=false` 与原因。
- **Debian 包**：单主包，包含三个程序、systemd user 单元、会话自启动条目、桌面入口、
  多尺寸图标与文档；依赖由 `dpkg-shlibdeps` 从二进制自动推导。

## 安装

```bash
sudo dpkg -i trafficview_1.0.0-1_amd64.deb
```

安装后由 `/usr/libexec/trafficview-session` 在登录时拉起守护进程；X11 会话下同时启动
悬浮窗，托盘常驻。也可以从启动菜单点击 **TrafficView** 手动启动同样的会话入口。

希望交给 systemd 托管守护进程时：

```bash
systemctl --user enable --now trafficviewd
```

从源码构建：

```bash
./packaging/build-deb.sh      # 质量门 + release 构建 + 生成 deb 与 SHA256SUMS
```

或只构建二进制：

```bash
cargo build --workspace --release
cargo build --manifest-path frontends/settings/Cargo.toml
```

## 系统要求

- Linux，amd64（本版仅构建该架构）
- 图形会话：X11 以获得悬浮窗与托盘；设置界面需要 GTK4 4.14+ 与 libadwaita 1.5+
- 运行依赖（由包自动声明）：`libc6`、`libgcc-s1`、`libgtk-4-1`、`libadwaita-1-0`、
  `libglib2.0-0` 等

## 配置与数据

- 配置：`~/.config/trafficview/config.toml`
- 历史库：`~/.local/share/trafficview/history.db`
- 卸载软件包：`sudo dpkg -r trafficview`；用户配置与历史不会被自动删除

## 已知限制与未验证项

- **悬浮窗仅覆盖 X11**：Wayland 会话不会自动启动悬浮窗。
- **不含 eBPF/AF_PACKET 特权 helper**：`process_traffic.backend` 选为 `ebpf` /
  `af_packet` 时会按不可用降级并给出原因；本包不安装对应 system 单元与 D-Bus 策略。
- **硬件相关采集器按需降级**：无 GPU、电池或温度传感器时对应字段不可用，不出现伪造零值。
- 已在 Deepin 25 + Cinnamon/X11、VirtualBox（无 GPU、单网卡）环境验证采样、D-Bus、
  悬浮窗、托盘、设置界面、历史与告警。
- 尚未验证：KDE Plasma / GNOME 的 Wayland 会话、waybar 实际渲染、XFCE 下 24 小时
  运行、网卡热插拔、休眠唤醒后的统计连续性、GPU 读数。
- VirtualBox 软件渲染下悬浮窗可能留下旧像素残影，属 X 重绘环境问题，非程序缺陷。
- **许可证尚未声明**：仓库当前未附带 LICENSE，公开发布前必须由项目所有者确定许可证。
