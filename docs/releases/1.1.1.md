# TrafficView 1.1.1 发行说明

发布日期：2026-11-26
发行产物：`trafficview_1.1.1-1_amd64.deb`

1.1.1 在 1.1.0 的 CPU/GPU 温度功能之上，调整默认体验并补充关于页面。

## 本版变化

- **默认主题 dark**：新配置与缺失 `theme` 字段的旧配置均默认深色；
  仍可选 `auto`（跟随桌面）或 `light`。
- **默认显示样式**：CPU 与 GPU 的温度默认内联在同一行、两个空格间距
  （`CPU 14%  70°C`、`GPU 12%  55°C`）；独立 `cpu_temp` 项保留在配置中
  但默认 `visible = false`，需要单独一行时可自行打开。
- **设置界面新增「关于」页**：应用图标、名称、版本号（随构建更新）、
  功能介绍与 GitHub 项目链接（点击用系统浏览器打开）。
- **文档更正**：发行版支持仅声明 Deepin 25 验证通过；Ubuntu 24.04 可安装
  但实测运行异常，原因待排查；Ubuntu 22.04 及更早版本受 GTK4/libadwaita
  与 libc6 依赖限制无法直接安装。
- **2026-11-28 注**：1.2.0 后续构建已修复 Wayland 会话下悬浮窗未自启动、降级窗口
  无法拖动的问题；Ubuntu 26.04 LTS（GNOME/Wayland）已验证正常，24.04 尚未复测。
  这些修复已汇总到 [1.2.1 发行说明](1.2.1.md)。

## 安装与升级

```bash
sudo dpkg -i trafficview_1.1.1-1_amd64.deb
```

已有配置文件不会被自动改写：如果你之前手动配置过内联温度，本次升级不影响；
如果想采用新的默认样式，可删除 `~/.config/trafficview/config.toml` 后重启
daemon 重新生成（会丢失其它自定义，建议先备份）。
