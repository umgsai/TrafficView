# TrafficView 1.2.0 发行说明

发布日期：2026-11-27
发行产物：`trafficview_1.2.0-1_amd64.deb`

1.2.0 在 1.1.1 的基础上加入 GUI 中英文多语言，并修复了部分发行版上悬浮窗
文字被渲染成符号的乱码问题。

## 本版变化

### 中英文多语言（GUI）

- 新增配置项 `language = "auto" | "zh" | "en"`，默认 `auto`：`LC_ALL` / `LANG`
  以 `zh` 开头时使用中文，其余（含未设置、`C` / `POSIX`）使用英文。
- 覆盖范围：托盘菜单与 tooltip、daemon 阈值告警消息与桌面通知、GTK4 设置界面。
- 设置界面「通用」页新增语言下拉（跟随系统 / 中文 / English）；保存后托盘与
  通知立即生效，设置界面需重新打开窗口。
- 文案集中在 `crates/core/src/i18n.rs` 的静态表（125 条，中英文 key 一一对应）；
  未知 key 回退英文表，仍无则返回 key 本身，不会 panic。
- D-Bus v1：`GetConfig` / `UpdateConfig` 增加 `language` 字段，非法值由
  `Config::validate` 拒绝。`UpdateConfig` 未携带该字段时保留当前值，初始默认为
  `auto`；缺少该字段的旧配置文件同样回退到 `auto`。
- 不翻译：CLI 帮助与输出、README/文档、悬浮窗显示项 label（属于用户配置）。

配置示例：

```toml
language = "auto"   # auto | zh | en
```

### 乱码修复

- 修复在部分发行版（如 Linux Mint）上悬浮窗数字与字母被渲染成 ✚★✓ 等符号的问题。
- 根因：cosmic-text 0.12 的字体回退只接受字重完全相等的字体。原实现请求
  `Weight::MEDIUM`（500），系统缺少 500 字重的无衬线字体时（默认族 `Fira Sans`
  也未安装），回退链全部落空并进入任意字体分支，最终按字体库 ID 选中
  `P052` / `D050000L`（Dingbats 符号字体）。
- 两处绘制路径改用默认字重，回退链恢复正常，命中
  `DejaVu Sans` / `Noto Sans` / `Noto Sans CJK SC`。

### 文档

- README 补充语言配置说明，以及卸载时删除本地配置与历史数据的命令。

## 安装与升级

```bash
sudo dpkg -i trafficview_1.2.0-1_amd64.deb
pkill -f /usr/bin/trafficview; sleep 1
setsid /usr/libexec/trafficview-session >/dev/null 2>&1 &
```

已有配置文件不会被自动改写；缺少 `language` 字段的旧配置按默认 `auto` 处理。
升级后如悬浮窗仍显示旧文字，说明仍在运行旧进程，按上面的命令重启会话进程即可。

## 系统要求

1.1.1 包实机安装运行通过，1.2.0 的构建与质量门亦通过。依赖仍由 `dpkg-shlibdeps`
从构建机二进制推导，详见 [1.1.0 发行说明](1.1.0.md) 的发行版支持表。
